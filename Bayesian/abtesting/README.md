# AB Testing and Statistical Significance

This folder contains a unified, command-line statistical suite for executing, simulating, and evaluating various statistical tests used in A/B testing and data analysis.

## Summary of Statistical Tests

All tests and simulations are implemented in a single unified script: **[abtesting_suite.py](file:///C:/Users/mrdat/PycharmProjects/pan-theory/Bayesian/abtesting/abtesting_suite.py)**.

| Test | Best Used For... | Type of Data | CLI Command |
| :--- | :--- | :--- | :--- |
| **Chi-Square Goodness-of-Fit** | Comparing continuous data distributions to a theoretical shape (e.g., normal). | Continuous / Binned Numbers | `python abtesting_suite.py --test goodness-of-fit` |
| **Chi-Square Independence** | Checking if categories are independent (e.g., did Ad A cause more clicks than Ad B?). | Counts / Categories (Yes/No, Ad A/B) | `python abtesting_suite.py --test chisq` |
| **T-Test** | Comparing averages in small groups or when population variance is unknown. | Numbers (Prices, Time spent, Weight) | `python abtesting_suite.py --test ttest` |
| **Z-Test** | Comparing averages or proportions in large groups (N > 30). | Numbers or Percentages | `python abtesting_suite.py --test ztest` |
| **Delta Method** | Estimating variance for ratio metrics (clicks/views) on clustered/clumpy data. | Ratios (Clustered Data) | `python abtesting_suite.py --test delta-method` |
| **Kolmogorov-Smirnov (KS)** | Checking if continuous samples match a specific distribution, or if two groups share the same distribution. | Continuous Numbers (e.g., times, scores) | `python abtesting_suite.py --test ks-comparisons` |

## Command Line Usage

Run the entire suite of statistical tests sequentially:
```bash
python abtesting_suite.py --all
```

Generate/regenerate `simulated_traffic.csv` data:
```bash
python abtesting_suite.py --generate-data
```

Run a specific statistical test or comparison demo:
```bash
python abtesting_suite.py --test <test_name>
# Options: chisq, goodness-of-fit, ttest, ztest, delta-method, ks-comparisons
```

## Kolmogorov-Smirnov (KS) Test Comparisons

The KS test is a non-parametric test used for continuous data. It is demonstrated via `python abtesting_suite.py --test ks-comparisons` through three comparisons:

### 1. KS vs. Chi-Square Goodness-of-Fit (Testing one distribution against a theoretical shape)
*   **Chi-Square**: Requires binning data into arbitrary intervals, which discards information and makes the result sensitive to the number/width of bins. Requires at least 5 expected items per bin.
*   **KS Test**: Compares the empirical cumulative distribution function (CDF) directly to the theoretical CDF. It is exact, requires no binning, and is strictly superior for continuous distributions.

### 2. Two-Sample KS Test vs. T-Test (Comparing two continuous groups in A/B testing)
*   **T-Test**: Compares group *means* only. If Group A and Group B have the same mean but totally different variance (e.g., Group B has much higher variance), the T-test concludes they are identical.
*   **KS Test**: Compares the overall distribution shape/variance. It will easily detect that the groups have different behaviors.
*   *Note*: Use the T-test if your business goal is strictly to increase the average of a metric; use the KS test to detect *any* change in user behavior.

### 3. KS Test vs. Chi-Square Test of Independence (For categorical/binary conversion metrics)
*   **Chi-Square / Z-Test**: Designed for categorical (success/failure) counts.
*   **KS Test**: Invalid for binary data. Since binary data (0 and 1) has massive ties, the empirical CDFs are step functions. Applying the KS test to such data results in mathematically invalid, highly conservative (unreliable) p-values.
